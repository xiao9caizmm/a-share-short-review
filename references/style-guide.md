# 样本文风提炼

## 文章骨架

交易日复盘固定使用：

```markdown
# YYYY-MM-DD+A股短线复盘

◆ 一、今日核心结论
一句话定性。先说指数和情绪，再说真正主线。必须指出市场矛盾。

◆ 二、市场全景数据
指数表 + 涨跌家数/涨停跌停/成交额。表后给一句判断。

◆ 三、⭐创历史新高与主线分析
创新高数量、行业分布、代表股、主线确认。强调"创新高是资金投票"。

◆ 四、连板股梯队
列高度、个股、题材、备注。判断晋级率和短线情绪。

◆ 五、资金流向与龙虎榜
主力资金、行业净流入、机构净买入/卖出、沪深股通/营业部重点。

◆ 六、风险提示
用表格列涨跌比、跌停数、缩量/放量、高位分歧、题材轮动。

◆ 七、操作建议
主攻、配置、防守、回避四栏。最后写一句人话总结。
```

## 语气模式

- "怎么说呢，今天这行情挺割裂的。"
- "说白了，资金不是没地方去，是只去确定性方向。"
- "指数看着一般，但个股赚钱效应不差。"
- "这不是全面牛市，是结构性行情。"
- "别被指数骗了，真正的票在创新高名单里。"
- "高位能看，但别满仓硬冲，留点现金等分歧。"

## 判断词

- 情绪强：百股涨停、跌停减少、连板高度打开、创新高扩容。
- 情绪弱：跌停偏多、晋级率低、放量下跌、高位股补跌。
- 主线强：创新高集中、主力净流入、龙虎榜机构/北向共振。
- 主线分歧：龙头流出、低位补涨、同题材内部分化。
- 风格切换：从高位大票切到低位小票，从权重切到题材，从老主线切到新催化。

## 禁忌

- 不写成券商研报腔。
- 不把资讯原文大段复述。
- 不给确定性收益承诺。
- 不因单日上涨就喊全面牛市。
